# BrandGuard AI — Quick Test Checklist

Run through these checks before recording a demo or submitting.

- [ ] Page opens with a sample draft and five example rules.
- [ ] Word count updates while editing.
- [ ] Analyze draft shows findings for `cheapest`, `guarantee`, `customers`, and the configured year mismatch.
- [ ] Preferred wording action changes the draft text.
- [ ] Approved fact action inserts the configured approved value; verify it manually.
- [ ] Dismiss finding changes its state and status filter.
- [ ] Add a new avoid rule and rerun analysis.
- [ ] Delete a rule and rerun analysis.
- [ ] Filter findings by open, accepted, and dismissed.
- [ ] Export report opens the report dialog.
- [ ] Download .txt saves a readable report.
- [ ] Reset demo restores sample data and default rules.
- [ ] Check on a mobile-width screen.
- [ ] Explain limitations honestly: rule-based, no connected AI model, no external fact verification, no backend.
